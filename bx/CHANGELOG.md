# bx changelog

## 0.2.0 — 2026-11-16

**语言**

- 条件表达式 `c ? a : b`（右结合，优先级低于 `||`、高于赋值）。
- 字符串插值 `"n=${x}"`，`\$` 转义字面美元。
- 闭包：任意嵌套深度、共享可变；只有被闭包引用的局部装箱成 cell，循环变量每轮独立。
- 键值迭代 `for k, v in xs`：对象给 key/value，数组与字符串给 index/value。
- 首行 `#!/usr/bin/env bx` 可执行脚本，行号不偏移。

**诊断**

- 运行时错误带函数名与定义文件，跨 `use` 与 `.bxb` 往返保留。
- include 内的编译错误指向被 include 的文件；缺文件报引用者；嵌套不叠前缀。
- `bx check [--json]`：只编译不执行，成功/失败都输出一行机器可读 JSON。

**运行时与 CLI**

- `--max-steps` / `--timeout` 执行预算；脚本之后的参数仍进 `argv`。
- `read("-")` 读 stdin 到 EOF，脚本可当管道过滤器。
- `exec_all`：最多 8 个并发，结果按输入顺序，单个失败隔离。
- `exec(..., {stdout, stderr})`：大输出直接落文件，绕开 8 MB 捕获上限。
- `spawn` 家族：后台进程 + `spawn_poll`/`spawn_wait`/`spawn_write`/`spawn_close`/`spawn_kill`。
- `test(name, fn)` + `bx test <file>`：语言原生测试运行器（汇总与退出码）。
- `patch(path, diff)`：原子应用 unified diff，上下文不匹配时不写文件。

**实验性 wasm 目标**

- 记录合并：`merge(a,b)` 在编译期合成 union shape（a 键序 + b 新键，重叠键取 b 值），支持链式；空对象字面量仍不支持。
- 记录内建：`keys`（字符串数组）/`values`（整型数组）/`has`/`get(record,key[,default])`，运行时按 shape 键表比较；缺省键无 default 时中止（VM 返回 null）。
- 捕获闭包补齐：`map/filter/reduce/each` 回调可捕获外层局部（回调 env 求值一次后传入）；全部可迭代对象（整型数组、字符串数组、记录、map）的循环变量均可被捕获（循环前分配一个 cell、每轮刷新，符合 VM 单共享绑定语义）。仍限制：同一变量持有不同字面量站点的函数值、记录数组。
- 捕获闭包：函数字面量新增 env 指针参数，被捕获的外层局部/参数装箱为堆 cell（共享可变状态，计数器语义与 VM 一致）；捕获分析在字面量体检查前运行、支持嵌套传递，并驱动推断 pass B。限制：循环变量捕获、内建高阶回调捕获暂不支持（明确报错）。
- 高阶内建扩展到字符串数组：`map` 回调返回 Str 时结果为字符串数组（Int 时整型数组），`filter` 保持元素类型；软推断能区分字符串数组字面量、遍历 `let` 初始化与 for-in 迭代器、推断回调内 `.len()`/混合 `+`。
- 高阶数组内建：`map/filter/reduce` 与语句级 `each`，接受非捕获函数字面量，emitter 内联循环并直接调用提升后的字面量函数。
