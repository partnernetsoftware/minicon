# v0.1.10 release history

Status: **released.** Public Release `v0.1.10` is published (not a draft). It
completes the `ui/ui-design` vision and stays dual-signed (Windows Authenticode
+ macOS Developer ID / notarization).

## Identity

- Source: `3cb919dc7a0e11c2ec36968d6fc8a8db79b2ba0a`, tag `v0.1.10`.
- `signing.mode=required` (Windows) and `signing.macos.mode=required` (macOS).

## What shipped (UI complete)

The deferred `ui/ui-design` pieces landed, so all five turns are now in:

- **Turn 4 — toolbar 7→2 + settings panel.** The header keeps two tools (New,
  Settings). The Settings panel carries interface language (English / 简 / 繁),
  font size (−/100%/+), a three-swatch theme picker (Neutral / Docs Ink / Paper
  Ink), and the keyboard shortcuts.
- **Turn 5 — grid crosshair.** A translucent row/column band plus 1px lines snap
  to the hovered cell (via a new `Surface::blend_rect`), and the status bar's
  fixed-width `L###:C###` readout follows it; toggled with `Ctrl+Shift+G`.
- Already shipped in 0.1.8/0.1.9: Simplified/Traditional locale, per-row close
  on hover, three runtime themes, the bottom status bar.
