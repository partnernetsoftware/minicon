# v0.1.11 release history

Status: **released.** Public Release `v0.1.11` is published (not a draft). It
adds per-theme terminal colors and stays dual-signed (Windows Authenticode +
macOS Developer ID / notarization).

## Identity

- Source: `98edb2b9e4a031046a8490212247e9762ea03ece`, tag `v0.1.11`.
- `signing.mode=required` (Windows) and `signing.macos.mode=required` (macOS).

## What shipped

- **Per-theme terminal colors.** Each theme now recolors the terminal body, not
  just the chrome: Neutral keeps the classic black console, Docs Ink is a
  deep-navy console, Paper Ink a light console with a legibility-tuned ANSI set.
  Adopts the conventional terminal color-scheme model (default background /
  foreground, cursor, and the 16 ANSI colors); indices 16..256 (the 6x6x6 cube
  and grayscale ramp) stay standard, and a program's own explicit color requests
  are never overridden. Colors live per `ConTerminal` and re-apply to every open
  tab on a theme change. Neutral is byte-for-byte the previous look.
- **Settings-panel shortcut lines no longer clip** — the sidebar-anchored panel
  was narrower than its descriptions ("New termina", "Soft newlin"); the
  descriptions were shortened to fit in all three languages (chords unchanged).
- Also in this line (docs, not the binary): the website was rebuilt around user
  value (input-first, scriptable, themes; Old Windows demoted to an appendix;
  AgenTerm decoupled), and signing facts were aligned across the site, the
  GitHub release notes, README, and the delivery PRD.
