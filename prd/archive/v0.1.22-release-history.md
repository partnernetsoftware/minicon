## What the local rounds found

- **Rosetta hung after the disk filled.** Every new x86_64 binary hung before
  `main`; restarting `oahd` (kill; launchd respawns) fixed it.
- **The Windows court had never run the full suite.** QGA file copy runs at
  ~240 KB/s; pushes outlived their 30 s bound and left guest files locked.
  utm-court `b87196c` fetches large files over HTTP instead: Windows `test`
  stage 227 s -> 72 s.
- **A font-dependent test.** `background_fill_spans_exactly_the_attributed_columns`
  sampled a glyph's centre; with Cascadia Mono the stroke covers it. Fixed by
  sampling blank cells (`0baccae`), assertions unchanged.
- **Gaps that predate 0.1.22** (v0.1.21 fails the same, in the same court):
  three `minicon_control` spawn-failure/multitab tests and
  `minicon_throughput` (`pty_drained_bytes` a few KB). Carried to 0.1.23.
