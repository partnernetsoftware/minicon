## Why 0.1.24 and 0.1.25 never shipped

Two version numbers were opened and abandoned before this one, both for
CI-only bugs that never touched a shipped byte:

- **0.1.24 → 0.1.25**: `defender-ci-scan.yml`'s clean-result regex only
  matched two guessed Windows Defender output patterns; real
  `MpCmdRun.exe -ScanType 3` output on `windows-2025` is
  `"Scanning <path> found no threats."`, matching neither. Fixed by
  broadening the match to three patterns.
- **0.1.25 → 0.1.26**: the same defender-ci-scan.yml fix, once pushed to
  `main`, moved `origin/main` past the 0.1.25 Candidate's pinned
  `source_sha` under the exact-source invariant then in force
  (`git rev-parse origin/main == source_sha`), invalidating that Candidate
  regardless of content. Restarted fresh as 0.1.26 rather than force stale
  content through an already-invalidated Candidate.

Each restart cost a full re-run of `minicon-com.yml` →
`company-signing.yml`/`macos-signing.yml` → `candidate.yml` for a change that
never touched a shipped byte. The owner flagged this as a systemic cost, not
a one-off: **"同一个版本号应该能断点续存"** (a version number should be able to
survive a mid-chain infra-only fix). See "The fix: product-source-hash"
below.

## The fix: product-source-hash

`scripts/product-source-hash.sh` (landed `ddf1cbc`, alongside its own selftest
`scripts/product-source-hash-selftest.sh`) hashes the tracked git tree at a
ref, **excluding** `.github/workflows/**`, `prd/**`, `plan/**`, `AGENTS.md`,
`PRD.md`, `README.md` — paths that cannot change what a release actually
builds or ships — while keeping `release-policy.json`, `Cargo.toml`/`Cargo.lock`,
`src/`, `crates/`, `scripts/`, `release/`, `loader/` in scope.
`candidate.yml` and `defender-ci-scan.yml`'s exact-source assertions now
compare this hash instead of raw `git rev-parse origin/main` equality, so a
workflow-only or doc-only fix landing on `main` mid-chain no longer forces a
version bump. Not yet exercised by a real mid-chain fix under this new
assertion — the next CI-only bug found during an in-flight release is the
first real test of it.
