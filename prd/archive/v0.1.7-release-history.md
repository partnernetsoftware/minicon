## Reputation: local UTM Windows Defender court

`release-policy.json` sets `reputation.mode=defender`. GitHub's Windows runners
disable Defender, so the verdict is produced locally against the sealed
Candidate's exact reputation asset set (`minicon.com`, `windows-x86_64`,
`windows-arm64`) in a disposable UTM Windows guest
(`research/minicon-com-loader/utm-win-defender-court.sh`, court
`win-aarch64-desktop`). Verdict **clean**, three assets, hashes unchanged after
an on-demand `Start-MpScan CustomScan` (Defender engine `1.1.26080.3`,
signatures `1.459.93.0`). `reputation_court.py qualify` produced the
`reputation-qualification.json` passed into the Reputation workflow.

Transport notes for this host's UTM 4.7: the court's file push refuses
transfers over ~4 MiB, so `minicon.com` (7,849,086 bytes) is split into <=3 MiB
parts and concatenated in-guest, verified byte-exact by the guest-reported
size. The concat glob must be unquoted (`copy /b prefix.part.* dest`): a glob
whose quote closes before the wildcard makes `cmd` copy nothing silently. The
scan runs synchronously (`exec` blocks until PowerShell exits) because a
detached launch is reaped by qemu-ga when the exec's `cmd.exe` returns; a
`taskkill` precedes each run so a retried exec never races a prior one.

## Product change

- `window-enum` now implies `process-spawn` in `agenterm-platform`. The Linux
  app inventory spawns a breakaway visible child to attach to a foreign
  window's session; without the feature edge a Linux cross-build failed on
  `crate::process_spawn` while a Windows or macOS host build never noticed.
  Fixed at agenterm `7036c239`, and minicon's pin moved to that revision.
- Six-cell qualification fixes for this Apple Silicon host (commits `34ba1f2`,
  `0136c1e`): test-module lints (`cargo fmt` + `clippy --fix`), a macOS-only
  control test that must not delete a running executable (kernel kills the
  process; failure is now injected with `chmod 000`), and the runtime-qualify
  scripts dropped an alignment stage already covered by the six-cell cargo
  test. No product logic and no test assertion was relaxed.
