## Signing

- **Windows**: `minicon.com` and both native `minicon.exe` cells are Authenticode
  signed as PARTNERNET SOFTWARE PTY LTD through Azure Artifact Signing (Public
  Trust). The candidate manifest records the signed after-SHAs; `candidate_bundle`
  and `release.yml` verify the shipped bytes are the signed bytes.
- **macOS**: the universal Mach-O is Developer ID Application signed (team
  `L2N7M5M544`), hardened runtime + secure timestamp, and Apple-notarized. The
  `tar.gz` carries the signed binary (Gatekeeper clears it online); a
  signed + notarized + **stapled** `minicon-0.1.9-macos-universal.dmg` ships
  alongside for offline Gatekeeper acceptance. Credentials were created via
  computer-use against the account holder's browser and live only in the
  `release-signing` GitHub Environment.
- The two signing switches are independent (`signing.mode` vs
  `signing.macos.mode`); this release is the first to turn both on at once.

## Reputation

`reputation.mode=defender`. A local UTM Windows guest ran an on-demand Microsoft

`windows-x86_64`, `windows-arm64`); verdict **clean**, hashes unchanged.
`reputation_court.py qualify` produced the qualification consumed by the
