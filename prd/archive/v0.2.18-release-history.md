# v0.2.18 release history

## User-visible result

[v0.2.18](https://github.com/partnernetsoftware/minicon/releases/tag/v0.2.18)
is public. The window and `--version` report 0.2.18. `Ctrl+Shift+N` inserts a
child beneath the active root or child. The Windows packages include the
explicit `rust-console` choice from `minicon-console`; the classic backend
remains the default. Screenshot control requests now return a typed error and
release their slot after a 30-second render/PNG timeout. Developer testing
gains explicit edit/integration profiles; inferred changed-path selection is
plan-only. A direct independent consumer checks the common `minicon-console`
API, while native session contracts across all OS/ISA cells remain open.

## Qualification scope and carried work

The final-source Windows x64 `l3` local gate passed: fmt, workspace Clippy,
canonical workspace and owned parser-fork tests, independent reuse consumer
and offline script self-tests. Explicit `control` edit selection executed 15
tests; `terminal` edit selection executed nine. The planner's offline guard
checks profile union, phase deferral, unknown-path full fallback and refusal
of a zero-test pass. This is development feedback, not a replacement for the
exact-source signing and artifact courts above.

On an earlier 0.2.18 source (`7a06266`), independent Claude Code 2.1.304,
Grok Build 1.0.62 and Codex CLI 0.162.1 sessions using the explicit Rust
backend retained tested Unicode, spacing and layout across narrow/wide/narrow
resizes and accepted a follow-up prompt. One earlier Grok screenshot request
remained pending; the final source bounds that request's lifetime but has not
located the missed-frame cause. Those sessions started hidden and are not an
exact signed-Candidate, visible-window three-agent acceptance matrix.

The classic Windows screen-buffer path still has measured astral-output and
real-TUI defects. Deterministic color/hue, sustained agent use, paste/cancel,
original API/PTY-wire attribution, exact-agent Candidate court, Rust backend
runtime on Windows ARM64, broader native API coverage, portable POSIX session
composition and latency/RSS baselines remain open with their owning PRDs.
The 0.2.16 test-selection and 0.2.17 modern-agent plans remain unfinished;
this release does not assert their full proposed gates or promote the Rust
backend to the default.
