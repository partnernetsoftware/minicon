# v0.2.19 release history

## User-visible result

[v0.2.19](https://github.com/partnernetsoftware/minicon/releases/tag/v0.2.19)
is public. The window and `--version` report 0.2.19. Four drifted multi-site
decisions now behave consistently: a collapsed sidebar insets the terminal by
the rail after a tab switch, Ctrl+Esc / Alt+Esc no longer dismiss the settings
panel, closing a tab from keyboard or control leaves the tree without blank
tail rows, and the composer's "SEND TO" band names the destination by the same
label the history records. `minicon.json` accepts a validated advanced `term`
override for new sessions; the default stays `TERM=xterm-256color` with
`COLORTERM=truecolor` and no emulation menu is offered. The portable session
contract vocabulary is now owned by `minicon_console::session` with the
platform facade re-exporting one type identity, and the shared POSIX PTY
mechanism lives in `adapters/unix/pty.rs` behind distinct Linux/macOS adapter
identities.

Behavior owners: [workspace](../PRD_02_25_con_workspace.md),
[terminal library](../PRD_02_35_terminal_library.md),
[reuse map](../PRD_02_28_shared_core.md) and
[terminal](../PRD_02_24_con_terminal.md).
