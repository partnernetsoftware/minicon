# v0.2.21 release history

## User-visible result

[v0.2.21](https://github.com/partnernetsoftware/minicon/releases/tag/v0.2.21)
is public. A browser tab is a terminal-tab peer with an embedded native page,
an address editor, Back/Forward/Reload, page title and loading/failure state.
Switching to a terminal hides the page; browser geometry excludes the terminal
composer. The replacement navigation icons use geometry instead of depending
on native font glyph coverage. Shutdown also gives accepted control replies a
bounded opportunity to finish before the process exits.

Behavior owners: [workspace](../PRD_02_25_con_workspace.md),
[control lifetime](../PRD_02_26_con_control_cli.md),
[shared/native browser boundary](../PRD_02_28_shared_core.md), and
[native development courts](../PRD_02_32_dev_loop_crosscheck.md).

The owner instructed publication on 2026-10-24 after the replacement's six-cell
and signed-artifact results were presented. This releases the owner UX gate for
this version. It does not assert a new manual Mac keyboard observation: physical
shortcut interception while WKWebView owns focus remains unmeasured.

the signed universal executable and the app inside the notarized/stapled DMG

on all six cells; these are exact-artifact courts, not a full unit-test matrix.
