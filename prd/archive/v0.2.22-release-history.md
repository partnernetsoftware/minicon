# v0.2.22 release history

## User-visible result

[v0.2.22](https://github.com/partnernetsoftware/minicon/releases/tag/v0.2.22)
is public. The visible New menu opens Terminal or the single reused Browser
root. Readable browser chrome includes an address editor and an editable proxy
field. Console/Web settings routes organize saved proxy choices; the browser
combobox applies a choice while retaining manual entry. Local service failure
shows bounded recovery actions, and returning to Terminal preserves its draft.

Behavior owners: [workspace](../PRD_02_25_con_workspace.md),
[browser preferences](../PRD_02_25_01_browser_preferences.md),
[shared/native boundaries](../PRD_02_28_shared_core.md), and
[control](../PRD_02_26_con_control_cli.md).
The owner explicitly requested public 0.2.22 on 2026-10-24.
Installation remains deferred for coordinated AgenTerm planning.

## Qualification and retained failed evidence

Downloaded clean-source unsigned receipts were checked against the source, shared pack digest, native binary hashes and real page/proxy/persistence assertions. Windows then qualified transformed APE/native executables; macOS qualified the signed universal bare executable and the app in its stapled DMG on both ISAs. Candidate packaging rehashed and executed its archives on all six cells. Public Promotion downloaded and verified Windows/POSIX assets. Every final run in the table uses attempt 1.
These are exact-artifact native browser/runtime courts; they do not imply an
unfiltered unit-test matrix or physical keyboard/IME evidence on every platform.

- Unsigned run [40073750173](https://github.com/partnernetsoftware/minicon/actions/runs/40073750173) at `73b98f7` failed: Windows redirected title; Linux active-proxy journey (polling exhausted replay cache).
- Unsigned run [40075261513](https://github.com/partnernetsoftware/minicon/actions/runs/40075261513) at `6ccaf56` failed: Both Windows native proxy view creations failed; macOS and Linux native preference journeys passed.
- macOS signing [40079791096](https://github.com/partnernetsoftware/minicon/actions/runs/40079791096) completed notarization to Accepted, then DMG ticket lookup lost its network connection (stapler exit 68). A bounded same-source replacement passed; Windows evidence was retained.
The Windows completion path reads the committed document title alongside title
notifications. The public smoke court observes one snapshot per proxy poll and
bounds polling to preserve room in the control replay cache, retaining final
failure observations instead of masking the original navigation failure.
Windows proxy environments now use distinct directories for distinct native options; native fixtures use an owned profile root instead of forcing every environment into one global WebView2 directory. The shared mechanism is owned by PRD 28. Local Windows cross compilation rejected an intermediate digest-formatting error before push; the corrected implementation reuses the existing URL-safe codec. A moved checkout required refreshing source-bound compile paths. During the cold rebuild a four-group local run timed out in the bounded concurrent-screenshot assertion; the unchanged-source two-group run passed all 31 local stages, with 14 unavailable courts still BLOCKED. The canonical serial full product gate passed in the new directory. These failures remain evidence; they were not relabeled as passes.

Earlier current-Mac evidence keeps its own identity/scope in the
[archived implementation plan](../../plan/archive/plan-v0.2.22.md): the complete
product gate recorded 1,313 passing tests, six ignored across 37 suites;
four opt-in native journeys were explicitly run; public native smoke retained
seven window captures. Physical page/host shortcut observations qualify only
the named Mac paths. The local six-cell receipt had 31 PASS, zero FAIL and
14 BLOCKED for unavailable native runners; inherited harness edits were kept
out of release commits, so that dirty local receipt is not clean release-source
proof. Clean CI receipts above are the released source/artifact evidence.

## Parallel workflow experience and remaining owners

The authorized parallel trial and its measured elapsed time, exclusive write
sets, failed controls and rework remain in the archived implementation plan.
[PRD 33](../PRD_02_33_test_orchestration.md) owns the durable lesson: independent
source files do not isolate a Cargo output root, desktop or clipboard. Compile
shared interfaces before delegating dependent work; serialize guard mutations,
builds and black boxes using the same canonical binary.

- Browser control editing, menu keyboard operation and focus consistency are
  the [next planned scope](../../plan/plan-v0.2.23.md), owned by PRD 25.02.
  This closeout does not start its feature implementation or bump its version.
- G4/G6, versioned modern-agent acceptance, native provider/session/library
  qualification, RSS and artifact-size work retain their existing owners and
  scoped limitations; archiving a version proposal does not close those gates.
- Defaults/authentication, provider OAuth, downloads, dashboard/wasm and
  additional Browser roots/content panels remain outside this delivery.
- Old plans and roadmap/hygiene ledgers stay under their archive indexes.
  Valuable negative controls and rejected decisions remain reachable; live
  entrypoints point to current capability owners and the next sequence.
