# v0.2.24 release history

## User-visible result and scope

[v0.2.24](https://github.com/partnernetsoftware/minicon/releases/tag/v0.2.24)
is public. Inline tab rename keeps editing when the user clicks inside its
field; tab branches can be reordered or reparented with a release-to-commit
gesture; and the status bar identifies native clipboard content type alongside
a truthful size or character count. The behavior contracts and remaining
acceptance are owned by [tab-tree interactions](../PRD_02_25_03_tab_tree_interactions.md)
and [clipboard status](../PRD_02_25_con_workspace.md#clipboard-status-type-and-size-shipped-core-in-0224).
The owner authorized public release of this named version and dynamic PRD/plan
adjustment. Publication does not relabel open native pointer, IME, scroll,
capture-loss, stale-tree, or public clipboard-pixel cases as passed. The
experimental Harness acceptance carried from 0.2.23 remains with its own
[provider gateway](../PRD_02_31_01_provider_gateway.md) owner.

## Retained failures and evidence limits

The first two macOS signing attempts signed the `.app` and received `Accepted`
notarization results, but `stapler` lost its Apple CloudKit ticket-delivery
connection (Error 68). Neither failed attempt was used by Candidate. Attempt
3 completed stapling, Gatekeeper validation and both signed native browser
cells. The failure record remains visible in the same workflow run history.

The first public-download smoke ran from the release-tag controller. Windows
and macOS passed, but Linux's eight-minute job limit expired while APT was
downloading WebKitGTK libraries from the hosted runner's Azure Ubuntu mirror.
No Linux browser result follows from that attempt. The smoke controller was
then changed on `main` to select the main Ubuntu archive and a bounded
15-minute Linux job; its checkout still pins the published `v0.2.24` tag and
its target is the same public archive bytes. The follow-up run passed all
three native smoke jobs, including the Linux archive checksum and browser
journey. The first timeout remains a failed historical attempt.

Earlier clipboard development courts exposed a 500 ms cold AppKit clear
timeout on both Mac ISAs and a 1500 ms timeout on hosted Intel macOS. The
isolated cleanup operation now has a separate finite 5 s bound; the final
source's native court passed all six cells. These hosted tests mutate only a
disposable initially empty clipboard. Synthetic pixel-surface checks and
Windows host-injected mouse tests do not establish physical keyboard, native
IME, every scale or a public screenshot of each status variant. Those cases
retain open identities in their behavior owners rather than inheriting a
release-wide PASS.
