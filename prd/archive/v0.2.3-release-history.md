## Reputation court evidence

`defender-ci-scan.yml` ran real `MpCmdRun.exe` (product 4.18.26080.4, engine
1.1.26080.3, signatures 1.459.440.0) against the exact Candidate-manifest
bytes on a `windows-2025` GitHub-hosted runner. `verdict: "clean"` for all
three policy-selected assets (`minicon.com`, `windows-x86_64`,
`windows-arm64`), each with `sha256 == post_scan_sha256`, proving the scan
did not alter the bytes it later shipped.

and `release.yml` an exact-SHA ref (their `GITHUB_SHA == source_sha` assertion
would otherwise break if `main` moved mid-chain). Deleted after the publish
completed.
