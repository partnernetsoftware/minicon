## First release driven from Windows

This is the first minicon release whose chain was driven from a Windows host
(Git Bash / GNU bash 5.2.15, MSYS). `scripts/release.sh 0.2.4` ran the whole
chain up to and including the Promotions dry run with no platform obstruction —
GNU `sed -i`, `date -f -`, `awk` and `mktemp` behaved as on Unix, and the
repository uses LF with `core.autocrlf=false`. The only stop was the script's
own interactive publish confirmation, which a non-tty session reads as EOF; the
real Promotion was then dispatched explicitly with
`scripts/ci-release.sh release`. See the `run-reputation-and-release` skill's
`references/troubleshooting.md` for the recorded conclusions and the follow-up
items this first Windows run raised.

## Pinned throwaway branch

`candidate-src-0.2.4` was created at the Candidate SHA to give `reputation.yml`
and `release.yml` an exact-SHA ref (their `GITHUB_SHA == source_sha` assertion
would otherwise break if `main` moved mid-chain). Deleted after the publish
completed.
