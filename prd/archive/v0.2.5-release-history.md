# v0.2.5 release history

Published 2026-10-11 under the owner's explicit 0.2.5 publication authority
(the owner named "打包发布minicon 0.2.5" as the round's goal, and chose
"先发布 0.2.5，再做 Phase E" when asked to sequence).
Public release: https://github.com/partnernetsoftware/minicon/releases/tag/v0.2.5
Source: `0326e2abaf71cb2f8dc22f766de9b410efa4be1e`.

Scope: the tab-tree work the owner asked for and a platform-layer ownership
move. Features — a pencil "edit" affordance on each tab row that renames the
tab inline (Enter/Ctrl+O commit, Esc cancel, all-whitespace restores the
derived label) and a second row under each tab showing the content terminal's
own OSC title, deliberately independent of the user's tab name; and the
Windows console-title gap fixed at the platform layer (the default
console-agent backend now reads `GetConsoleTitleW` and emits the same
control-free OSC 0 sequence the ConPTY backend already produced). Move —
the shared platform layer left `agenterm`, was renamed `minicon-*`, and now
lives here as in-repo members (`crates/minicon-platform`,
`crates/minicon-ui-core`, `third_party/{vt100,softbuffer}`); `agenterm` is to
depend on MiniCon (Phase E, a separate cross-repo change). Also fixed: two
stale/incorrect `contained_process` tests (which had never run because
agenterm's default build does not enable `contained-process-spawn`) and six
workspace clippy lints in the copied Windows code; README cut 436 → ~155 lines
and the landing page condensed to match. Record: `plan/plan-v0.2.5.md`.

## Notes

- The chain was driven from a Windows host. `scripts/release.sh 0.2.5` failed
  at its `1/8 bump` step with an empty commit because `Cargo.toml` had already
  been bumped to 0.2.5 by hand while `release-policy.json` still read 0.2.4;
  the bump was completed by hand (release-policy.json → 0.2.5, commit
  `0326e2a`) and steps 2–8 were driven with the same dispatch sequence
  `release.sh` encodes. `source_sha` was pinned to `0326e2a` throughout.
- Local six-cell was not run on this host: it cross-compiles Apple/Linux cells
  and needs `clang`/`llvm-ar`/`zig`/`python3`, which this Windows host lacks;
  the real cross-cell qualification ran in CI as `minicon-com.yml` (run
  38121360762), step 2 of the chain. The local Windows gate
  (`env -u AGENTERM_FORCE_CONSOLE_AGENT ./scripts/build.sh test`, exit 0; plus
  `cargo fmt` and `cargo clippy --workspace --all-targets -- -D warnings`
  clean) was green before the push.
