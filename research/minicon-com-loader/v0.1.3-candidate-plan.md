## G2 — six native cells: smoke + GUI/control black-box

Smoke (already in `minicon-com.yml`): `--version` equals `minicon 0.1.3`,
unknown flag nonzero, `--status` has `pty backend`.

**Add** (new step, same downloaded `minicon.com`, still no compile):

Product code has **no** `wait-ready` verb. Do not borrow UTM court
`wait-ready` (that is VM job-agent protocol, not MiniCon).

There is **no** `MINICON_CONFIG` environment variable in this repository.
Do not invent one.

Config path truth (agenterm-platform `649174e3` `runtime::user_config_directory`):

- Darwin / Linux: `HOME` + `/.config/minicon.json`. Linux does **not** read
  `XDG_CONFIG_HOME` for MiniCon config. `XDG_CONFIG_HOME` / `XDG_RUNTIME_DIR`
  may be set as **desktop/runtime auxiliaries** (sockets, portals) but are
  not the product config root.
- Windows: `SHGetFolderPathW(CSIDL_APPDATA, SHGFP_TYPE_CURRENT)` +
  `minicon.json`. **Not** `USERPROFILE` / `APPDATA` env. Setting those
  variables does **not** isolate Windows config.

**Windows G2 isolation = choice B** (choice A, a tested cross-platform
config-path override in MiniCon, is **not** taken for this Candidate).

B means:

- Candidate-of-record Windows cells run on a **clean dedicated** court:
  GitHub-hosted `windows-2025` / `windows-11-arm` ephemeral VM, or local
  UTM **disposable** clone. Reused interactive profiles are not G2 evidence.
- Before GUI start, record a **read-only baseline** of the CSIDL_APPDATA
  `minicon.json` path (absent or hashed bytes). After exit, the same path
  is in the black-box log. Baseline is evidence, not an env override.
- Still required on every cell (including Windows): unique `--control`
  (`unix:<abs>/control.sock` or `pipe:<unique-name>`) and a unique working
  directory for this run's files.

Darwin/Linux may isolate `HOME` to a temp tree (that **does** move
`~/.config/minicon.json`).

Ready rendezvous: loop `minicon.com cli --control ENDPOINT list-tabs` until
it succeeds (or a new script that is only that loop). Then:

1. start GUI (`minicon.com --control ENDPOINT` under the isolated env)
2. ready = `list-tabs` loop
3. `send-text` to a tab from `list-tabs`
4. `capture-pane` **or** `ui-snapshot`
5. clean exit (`close-window` and/or process exit 0); no leftover extract dir

Cells and runners (same labels as smoke):

| cell | runner | GUI court |
|------|--------|-----------|
| osx-aarch64 | macos-15 | native Aqua |
| osx-x86_64 | macos-15-intel | native Aqua |

| win-aarch64 | windows-11-arm | native GUI |
| lnx-x86_64 | ubuntu-24.04 | `xvfb` / existing product Wayland-or-X black-box, **not** compile |
| lnx-aarch64 | ubuntu-24.04-arm | same |

Local lane may use Lima/UTM as the Linux/Windows courts; GitHub native
runners are the Candidate-of-record courts.

**Pass:** six runtime receipts + aggregate; each receipt `job_status=success`
