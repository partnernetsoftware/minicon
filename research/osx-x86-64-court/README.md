# macOS x86-64 court experiment

Run `./research/osx-x86-64-court/preflight.sh` from repository root. It checks
whether the one-pair C1 experiment can begin without guessing local media or
silently adopting an unqualified appliance. The governing decision tree is
`plan/design-osx-x86-64-court-experiment.md`.

Do not place installers, VM bundles, screenshots containing identity, or
expanded host-home paths in this directory.
